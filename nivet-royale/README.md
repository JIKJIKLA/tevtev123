# NIVET ROYALE

[Play on GitHub Pages](https://jikjikla.github.io/tevtev123/nivet-royale/)

Standalone solo browser game with a Chapter 1-inspired island, supplied character models, fifteen bots, looting, building and a shrinking storm. Keyboard and mouse are required. This folder is independent of the Nivet League game at the repository root.

WASD moves; mouse looks; left click fires or places; right click aims; Shift sprints; Ctrl crouches/slides; Space jumps, drops or deploys the glider; E picks up; R reloads;1–6 selects; Q toggles building; F edits; Shift+F resets; V changes material; H/J heals/shields; Escape pauses. If the embedded preview denies mouse capture, click and drag to look.

Includes the supplied Tilted Towers, Lazy Links, Dusty Divot, Dusty Diner, Retail Row and Lucky Landing scenes, 53 additional outfits, and Chapter 1 nature assets. Terrain and connecting roads are reconstructed from the supplied overview; the whole island is not a 1:1 recreation. Some source vehicles lacked diffuse images, so their paint was reconstructed from surface masks. First load downloads about 200 MB of environment data; outfits load on selection. Animation and bot navigation remain approximate. Chromebook performance has not been measured. [Credits](CREDITS.md).

This directory contains the prebuilt client and its required runtime files. It requires no server, accounts or package installation. The editable Vite project and source archive are maintained separately.
