# 9.0 — Precision

This release brings measured handling, corrected boost routes and match endings to the surviving 8.2 game, with a default graphics preset aimed at Chromebooks.

New: camera customization, keyboard rebinding, standard-controller play, body-specific collision profiles and fitted car visuals. Improved: throttle/turning curves, coasting, aerial rotation, ball drag, kickoff positions, boost pickup bounds, zero-second continuation and overtime. Multiplayer now isolates protocol-4 matchmaking and validates complete snapshots before applying them.

The development source and build process are restored. The original build remains in the repository as a recovery copy. Existing media is reused; no paid generation credits were spent.

The target is smooth 60 FPS, subject to actual device testing. Advanced mechanics and remaining approximation boundaries are recorded in ACCURACY.md.
